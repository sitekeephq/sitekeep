# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately through GitHub:
**Security → Report a vulnerability** on this repository (private vulnerability reporting).
If you cannot use GitHub, write to sitekeep@7dimensions.eu.

Include what is affected, how to reproduce it and the impact you expect. We confirm receipt within
three working days and keep you informed until a fix is released. Please give us reasonable time to
fix the problem before any public disclosure.

## Supported versions

Security fixes are released for the latest minor version of SiteKeep Community. On-premises
installations should follow the upgrade steps in the release notes.

## Scope

SiteKeep Community (this repository) and its official container images. Enterprise modules and the
hosted cloud service are covered by the same reporting channel.
